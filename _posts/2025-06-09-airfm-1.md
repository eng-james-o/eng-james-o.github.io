Designing a drone starts with selecting the right airfoil. **Airfm** is a software tool created to streamline this process by allowing users to create, manipulate, and analyze airfoils with ease.

{% include image.html src="/assets/images/airfm-ui-main.png" alt="Airfm Main User Interface" caption="The clean and functional UI of Airfm." %}

### Key Features
- **Airfoil Library**: Access a wide range of standard airfoils.
- **Manipulation Tools**: Scale, rotate, and modify airfoil geometry.
- **Visual Feedback**: Real-time plotting of airfoil profiles.

Airfm is designed to be the go-to tool for drone builders looking to optimize their designs for better performance.
