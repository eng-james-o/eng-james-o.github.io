Airfm: Airfoil Manipulation Software

{% include image.html src="/assets/images/splash-screen.png" alt="Airfm Software Interface" caption="The Airfm user interface for airfoil analysis." %}

Problem

Aeronautical designers and drone builders often struggle with fragmented tools when selecting and modifying airfoils. Manually tweaking coordinates and running separate simulations is time-consuming and prone to error.

Solution

Airfm provides a unified platform to create, manipulate, and analyze airfoils. With an intuitive UI and integrated mathematical engines, it simplifies the transition from geometric design to aerodynamic analysis.

{% include image.html src="/assets/images/airfm-library.png" alt="Airfm airfoil selection library" caption="Airfoil airfoil library." %} {% include image.html src="/assets/images/airfm-main.png" alt="Airfm main airfoil editing interface" caption="Main airfoil editing interface." %}

Results

  • Reduces airfoil selection time from hours to minutes.
  • Standardized airfoil data export for CAD and CFD tools.
  • High-fidelity visualization of aerodynamic coefficients.

Tech Stack

  • Languages: Python, QML.
  • Libraries: NumPy, Matplotlib, PySide2.

Impact

Airfm empowers drone enthusiasts and professional engineers alike to make data-driven decisions during the conceptual design phase, leading to more efficient and higher-performance aircraft.
